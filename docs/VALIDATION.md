- Java runtime assets need internet/CDN access. Local arbitrary code execution is not part of this POC.
- Tests simulate IME document outcomes, not every OS/input method's live event behavior. The hour-long recording check is synthetic, not an hour of live typing.

### Active solving time and automatic pause — November 18, 2026

- Raw evidence `at` timestamps remain wall-clock values for ordering, recovery and provenance. Replay duration, event positions, coach-selected ranges, heuristic gap detection and agent event context now use active solving milliseconds with pauses subtracted. Historical recordings use their existing saved pause boundaries without rewriting evidence.
- Pause/resume events update the assessment clock in the same transaction as their recording event. The browser freezes immediately and retains unsent boundaries in IndexedDB; a buffered pause can recover after the original deadline if the attempt was not sealed. Old save acknowledgements reapply newer pending boundaries instead of undoing an automatic pause.
